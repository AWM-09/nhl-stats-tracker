Data notes

COVERAGE
The NHL Stats REST API provides separate skater, goalie and report datasets. Historical coverage varies by statistic and season.
Traditional scoring statistics have broader historical coverage than some tracking and advanced metrics. A missing value is not the same as a reported zero. The API is undocumented and community-documented; endpoint changes may affect availability.
Data: NHL Stats REST API and NHL Web API. Independent fan-made project; not affiliated with the NHL. Community API reference.
